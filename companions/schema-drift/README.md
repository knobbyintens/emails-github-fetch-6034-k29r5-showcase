# Schema Drift

**Status: Released — v0.9.1**

Contract diffs for evolving event streams.

## Install

```
pip install schema-drift
```

## What is included

- Field-by-field compatibility classification
- Breaking / risky / compatible change tags
- Markdown migration notes for review threads

## Layout

- `src/schema_drift/diff.py`
- `src/schema_drift/notes.py`
